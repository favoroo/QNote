- **State & Data Wiring**: All child modules (AI, Diary, Notes, Todo, Statistics) interact with a unified `DatabaseHelper` singleton for SQLite persistence and a `ConfigRepository` for app-wide settings, ensuring data consistency across features.
- **Navigation Shell**: Uses `go_router` with `StatefulShellRoute` to manage the five primary tab branches (Diary, Notes, Todo, AI, Statistics), preserving each module's scroll/state context during switching.
- **Platform Abstraction**: Conditional imports (`database_init.dart` vs `database_init_io.dart`) and platform checks (`kIsWeb`) in core services (Notifications, Database) allow the same Dart codebase to target Android, Windows, and Web with appropriate native integrations.
- **Cross-Module Services**: Shared infrastructure like `NotificationService` (for Todo reminders) and `SyncScheduler` (WebDAV backup) are initialized in `main.dart` and accessed via singletons or Riverpod providers, decoupling feature logic from system-level operations.
- **Theming & Configuration**: A global `theme_provider` and `app_theme` drive the visual identity, while `config_repository` manages dynamic feature flags and user preferences (e.g., AI configs, shortcuts) that influence multiple child modules.
