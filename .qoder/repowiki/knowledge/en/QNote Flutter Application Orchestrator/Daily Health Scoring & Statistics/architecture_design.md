- **UI Layer**: `StatisticsPage` acts as the main entry point, utilizing a tabbed interface (`_TabSwitcher`) to navigate between different statistical domains (Sleep, Diet, Finance, Mood, Activity, Score). It delegates rendering to specialized widgets like `DailyScoreStats`.
- **State Management**: Leverages `flutter_riverpod` with `AsyncNotifierProvider` (`dailyScoreProvider`) to manage the lifecycle of daily scores, including loading, error handling, and refreshing. `selectedDateProvider` enables date-based navigation and context switching.
- **Business Logic**: `DailyScoreNotifier` orchestrates the scoring process by aggregating diary records, fetching user profile/weight data, and invoking the `AiService` for analysis. It ensures data consistency by deleting old scores before re-scoring.
- **Data Persistence**: `DailyScoreRepository` handles CRUD operations for `DailyScore` entities in the local database, integrating with `SyncLogRepository` to track changes for potential synchronization.
- **AI Integration**: The `AiService` constructs complex prompts using user records and profile data, sending them to configured LLM providers (Gemini/OpenAI-compatible) to generate structured JSON scores and textual suggestions.
