  • ReAct 引擎（agent_loop.dart，668 行）：20 轮循环上限、超 30 条消息触发 LLM 摘要压缩、只读工具并行/写工具串行、用户取消令牌桥接 HTTP 断连、图片降级重试、<thought> 流式过滤。
  • 工具层（agent_tool_registry.dart）：VFS 原语 8 个（list_dir / read_file / write_file / write_files / edit_file / move_file / delete_file / view_image）+ 通用 6 个（grep / fetch_url / web_search / generate_image / skill / ask_user），全部硬编码全量注册。
  • 技能层（skill_registry.dart，697 行）：8 个内置技能为 Dart 常量（todo/note/timeline/journal/folder/settings/stats/frontend-design），用户技能持久化于 app_configs 并映射到 VFS /skills/；skill 工具支持 section 章节级按需加载。
  • 记忆层：/memory/user.md（用户画像与习惯）+ agent.md（小Q手记），条目一行一条，对话开始冻结快照注入、中途写入下轮生效 —— 已对齐 Hermes 记忆语义。
  • 上下文层（agent_support.dart）：系统提示词（硬编码 150 行）+ 动态环境上下文（当前时间、用户资料、长期记忆、附件导出）。
  • VFS（virtual_workspace_service.dart，2,858 行）：将待办/笔记/时间线/日记/配置统一抽象为根目录 / 下的虚拟文件系统，/settings/*.json 写入即时刷新 UI。

AI 服务底座（lib/core/ai/）

  • AiService：OpenAI 兼容 /chat/completions + Gemini 双协议，流式 SSE 解析（正文 / reasoning / 工具参数三类 chunk），原生 tool_calls 解析，超时与 429/5xx 指数退避重试。
  • AiRoleService：assistant（小Q主对话）与 timelineOptimization（时间线提纯）双角色模型绑定、独立温度与 MaxTokens。
  • 免费模型体系：内置 6 文本 + 2 生图模型，SenseNova Key 池轮询、动态 CPA 端点刷新、失败自动切换（free_model_executor）。

结论：QNote 已具备完整 Agent 形态，与 pi-agent / opencode 的「VFS + 原语工具 + ReAct」路线一致，具备承接 Hermes 高阶能力设计的地基。

2Hermes Agent 设计要点提炼

来源：hermes-agent.nousresearch.com 官方文档 13 个功能页 + 首页/插件页补充发现

Personality 个性

SOUL.md 持久身份文件占据系统提示词第一槽位，与 AGENTS.md（项目规范）职责分离；内置 helpful / concise / kawaii / pirate 等预设，/personality 可临时切换，配置文件支持自定义个性。

Skills 技能

遵循 agentskills.io 开放标准存放于 ~/.hermes/skills/；每个技能自动注册为斜杠命令（如 /gif-search）；Level 0~3 渐进式披露加载；Agent 自己可创建与修改技能。

Context References 上下文引用

@file:path、@folder:、@diff、@url: 内联注入内容；引用超上下文 25% 警告、超 50% 拒绝展开；敏感路径（~/.ssh 等）黑名单拦截。

Curator 技能维护

跟踪技能被查看/使用/修补频率；长期未用走 active → stale → archived 流转；空闲时派生短暂 AIAgent fork 后台整理；归档而非删除（最坏结果进 .archive/ 目录）。

Toolsets 工具集

工具按命名集合管理：Core（file/web/terminal）、Composite（debugging = file+terminal+web）、Platform（hermes-cli）；支持 CLI、配置文件、会话内 /tools enable|disable 三种配置方式。

Memory 记忆

双文件 MEMORY.md（2,200 字符）+ USER.md（1,375 字符）；会话开始冻结快照注入保 prefix cache；memory 工具增删改条目；满时整合替换。Honcho 插件提供语义检索增强。

Tool Search 工具搜索

渐进式披露：MCP/非核心工具 schema 占上下文 ≥10% 时激活；桥接三件套 tool_search → tool_describe → tool_call；BM25 检索 + 字面子串回退；内置核心工具始终直接暴露。

Document Extraction 文档提取

read_file 自动转换 .ipynb/.docx/.xlsx（内置）与 PDF/EPUB/ODF（懒安装转换器）为 Markdown，offset/limit 分页；扫描件检测覆盖率并告警，按需升级 OCR 或视觉分析。

Cron 定时任务

单一 cronjob 工具统一管理（创建/暂停/编辑/触发）；自然语言转 cron 表达式；任务可附加 skill；支持无 Agent 脚本模式（零 LLM 参与）；cron 运行内禁用 cron 工具防递归。

Context Files 上下文文件

项目级 .hermes.md → AGENTS.md → CLAUDE.md 优先级发现 + 子目录渐进式加载；统一安全扫描（提示注入/凭据窃取模式）与分层截断（70% 头 + 20% 尾）。

LSP（写后语义诊断）与 Mixture of Agents（多模型聚合）为编码/成本特化设计，QNote 暂不适用。

4本次四项实施设计

实施顺序：个性系统（含提示词拆分）→ 工具开关 → 技能治理 → 输入增强

① 个性系统（SOUL.md 模式）

  • 职责分离：QSystemPrompt 拆为「人格段（可配置）+ 能力规范段（内置）」，对齐 Hermes 的 SOUL.md / AGENTS.md 分层。
  • 五个预设：经典管家（默认，保持现有行为）/ 活泼元气 / 简洁干练 / 温柔陪伴 / 自定义文本；每个 prompt 仅 3~6 句描述身份语气。
  • VFS 集成：新增 /settings/personality.json 端点 —— 小Q自己也能改性格（「你以后活泼一点」→ 写配置，下轮对话生效）。
  • 入口：侧边抽屉新增「小Q个性」页，预设卡片单选 + 自定义编辑。

② 输入增强（斜杠命令 + @ 引用）

  • 斜杠命令：输入 / 弹出技能浮层，选择后补全为 /todo-manager 整理待办；发送时技能手册经 extraSection 通道注入（不污染消息原文）。
  • @ 引用：输入 @ 弹出 VFS 目录树逐级选择，插入 @/todos/工作/xx.md；发送时读取文件内容注入上下文，单文件超 4,000 字符截断（对齐 Hermes 软限制）。
  • 范围：仅全屏对话页；悬浮小Q浮层空间小，列为后续。

③ 技能治理（Curator 轻量版）

  • 使用统计：skill 工具每次成功加载手册即记录次数与最近时间（fire-and-forget 落盘，不影响主流程）；技能页展示「使用 N 次 · 最近 MM-dd」。
  • 沉睡标记：超 90 天未用的用户技能标记「沉睡」。
  • 归档而非删除：归档技能从系统提示词索引与 skill 清单中隐藏，技能页「已归档」区可随时恢复。

④ 工具开关（Toolsets 轻量版）

  • 分层：核心工具（VFS 8 件 + skill + grep + ask_user）不可禁用；可选工具 fetch_url / web_search / generate_image 用户可启停。
  • 提示词联动：禁用工具时，系统提示词中对应行动准则段（网页阅读/网页搜索/图片生成）同步不注入，避免模型按不存在的工具行事。
  • 入口：AI 设置页新增「小Q工具能力」区块，切换即时保存、下次对话生效。

核心洞察

Hermes 架构的本质是「按需加载 + 安全边界 + 渐进式披露」：工具按集管控、知识按需查阅、记忆有界治理、上下文分层注入。QNote 的 VFS + 原语工具路线已与之同构，本次四项实施补齐的是「可配置的人格」「显式的触发入口」「有生命周期的技能库」「可裁剪的工具面」—— 让小Q从"固定出厂的助手"进化为"用户可塑造的伙伴"。
