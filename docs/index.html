04 / Local-First

你的数据，
只待在你自己的地盘上。

本地优先存储

所有记录先写入设备本地 SQLite，不经过任何第三方服务器；软删除 + 回收站机制兜底，误删可恢复。

零遥测零账号强制离线可用

把你自己的云当同步后端：坚果云、Nextcloud、群晖、自建 Nginx 皆可；文本与图片全量同步，日志逐条可查。

全量同步增量日志冲突可控
